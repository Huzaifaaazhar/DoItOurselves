# Decisions

- Next.js static export (`output: "export"`) so one `out/` folder serves both the web build and the Capacitor Android app.
- Fonts from `@fontsource` instead of `next/font/google`: identical Google fonts, self-hosted, and the build never needs network access.
- Phase 1 keeps the existing imperative three.js engine inside a client component so the game stays playable; R3F port is Phase 3.
- No Rapier: lane-runner collisions are 1D lane + distance checks; a physics engine would add ~400 KB for nothing.
- Shots drive the real game through `window.__game` instead of a separate freeze mode; deterministic enough for visual QA.
- Poster image is regenerated by `npm run shots` from the menu scene, so it never drifts from the real look.
- Route distances are compressed (600 game metres per real km) so a full ride is a few minutes.
- Debug APK is built in GitHub Actions (free) so the user can install without a local Android setup; release signing stays manual (keystore never in git).
- One icon source (`src/components/icons/paths.ts`) feeds both the DOM screens (`iconSvg`) and React (`<Icon />`), so the set can't drift.
- Primary action = yellow warning-sign plate with ink border; secondary = black label plate with paper border (from the mockup's HUD labels). Chamfered corners via clip-path read as cut sheet metal.
- Title is a green University Road gantry sign (Urdu + English), not a logotype: it's the one image every Karachi commuter knows.
- Campus gates passed along the way stand beside the road; only the destination gate spans the road, so the arrival shot frames it.
- `/dev/gallery` is compiled only with NEXT_PUBLIC_DEV_ROUTES=1; production builds render 404 there.
